# homebrew-tap

Personal Homebrew tap for [vtrenton](https://github.com/vtrenton)'s tools.

```
brew tap vtrenton/tap
```

## Available

- [`tshx`](https://github.com/vtrenton/tshx) — `brew install vtrenton/tap/tshx`

Casks in this tap are generated and pushed automatically by [GoReleaser](https://goreleaser.com/) — don't edit them by hand.
